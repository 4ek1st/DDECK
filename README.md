# DDECK for Windows

> Закрытое приложение для Windows. Этот публичный репозиторий содержит только страницу загрузки и готовые релизные файлы — исходного кода DDECK здесь нет.

## Скачать

**[Открыть последний релиз](https://github.com/4ek1st/DDECK-Downloads/releases/latest)**

1. В разделе **Assets** скачайте файл, имя которого начинается с `DDECK-` и заканчивается на `-win-x64.zip`.
2. Сверьте SHA-256 с файлом `SHA256SUMS.txt`.
3. Полностью распакуйте ZIP в обычную папку с правом записи.
4. Запустите `DDECK.exe`.

Не скачивайте автоматически созданные GitHub-архивы **Source code (zip/tar.gz)** — в них находится только содержимое этой публичной страницы, а не приложение.

## Что важно знать

- Сборка предназначена для Windows x64.
- Требуется Microsoft Edge WebView2 Runtime.
- Это preview-версия без цифровой подписи; Windows SmartScreen может показать предупреждение.
- При первом запуске DDECK создаёт уникальный локальный access token.
- Пользовательские настройки и данные создаются локально после запуска и не входят в скачиваемый архив.
- Необязательные онлайн-интеграции требуют отдельного явного подключения.

## English

DDECK is a closed-source Windows application. This public repository contains only download information and compiled release files.

Download the asset named `DDECK-…-win-x64.zip` from the **[latest release](https://github.com/4ek1st/DDECK-Downloads/releases/latest)**, verify it against `SHA256SUMS.txt`, extract the complete archive, and start `DDECK.exe`.

The preview is currently unsigned, so Windows SmartScreen may display a warning. GitHub's automatically generated “Source code” archives contain only this public download-page repository, not the DDECK application source.
