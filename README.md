# DDECK for Windows

Official downloads for the closed-source DDECK application.

## Download

**[DDECK-Setup.exe](https://github.com/4ek1st/DDECK-Downloads/releases/download/v0.1.0-preview.1/DDECK-Setup.exe)**

Windows x64 · Installer · Preview

A portable ZIP is also available on the [release page](https://github.com/4ek1st/DDECK-Downloads/releases/tag/v0.1.0-preview.1).

The DDECK application source code is private and is not included in this repository or GitHub's automatically generated source archives.

> This preview is not digitally signed, so Windows SmartScreen may show a warning.
